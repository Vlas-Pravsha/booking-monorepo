# Smart Booking System (MVP) 🚀

**Smart Booking System** — це інтелектуальна SaaS-платформа для ресторанів, побудована на базі T3 Stack. Основна перевага системи — використання AI для аналізу завантаженості та автоматичного стимулювання бронювань у «мертві години».

## 🎯 Бізнес-мета MVP

Максимізувати прибуток ресторану шляхом заповнення «дірок» у графіку бронювань. Замість простого функціоналу запису, ми пропонуємо інструмент активного управління попитом.

## 🛠 Функціональні модулі

### 1. Адмін-панель закладу

- **Реєстрація та брендований піддомен:** Кожен клієнт отримує посилання виду `restaurant-name.table-reserve.com`.
- **Керування ресурсами:** Спрощений конструктор списку столів із зазначенням місткості.
- **Гнучкий графік:** Налаштування годин роботи та середньої тривалості візиту.

### 2. Портал бронювання (Client-facing)

- **Інтуїтивна форма:** Вибір дати, часу та кількості осіб у 3 кліки.
- **Smart Availability:** Система показує лише ті столи, які дійсно вільні, враховуючи тривалість попередніх та наступних броней.
- **Анти-спам верифікація:** Підтвердження через код у Telegram або SMS.

### 3. Операційне керування (Timeline)

- **Інтерактивна стрічка:** Список усіх замовлень на сьогодні з можливістю швидкої зміни статусу («Очікується», «Прийшов», «Скасовано»).
- **Walk-in інструмент:** Можливість персоналу миттєво додати клієнта, який прийшов без попереднього запису.

### 4. AI-модуль «Розумні години» 🧠

- **Аналізатор попиту:** Алгоритм аналізує завантаженість за останні дні та виявляє проміжки з найнижчим попитом.
- **Гібридний підхід (Cold Start):** На початковому етапі власник може вручну вказати «мертві години» (наприклад, Пн-Чт 14:00-17:00). AI почне автоматичне навчання після накопичення перших 50-100 бронювань.
- **Динамічне стимулювання:** Система автоматично підсвічує «непопулярні» слоти на сторінці бронювання міткою (наприклад, _-20% на цей час_).
- **Прогнозний дашборд:** Візуалізація очікуваного заповнення залу на наступний день.

### 5. Автоматизація та сповіщення (Telegram First)

- **Для клієнтів:** Верифікація через OTP у Telegram та нагадування за 2 години до візиту.
- **Для адмінів:** Telegram-бот як основний робочий інструмент — миттєві сповіщення з кнопками «Підтвердити» або «Скасувати» прямо в месенджері.

## 🛡 Технічні особливості

- **Запобігання Race Conditions:** Використання транзакцій на рівні БД та тимчасове блокування слотів (на 5-10 хв) під час процесу бронювання для уникнення подвійних записів.
- **Tenant Isolation:** Чітке розділення даних між різними ресторанами на рівні запитів до БД.

## 🔄 Життєвий цикл взаємодії (User Journey)

1.  **Налаштування:** Ресторатор реєструється та створює конфігурацію залу.
2.  **Аналіз:** AI аналізує поточний стан та виділяє слоти для «Щасливих годин».
3.  **Бронювання:** Гість бачить вигідну пропозицію на сайті, обирає час та проходить верифікацію.
4.  **Підготовка:** Адміністратор отримує сповіщення, бачить бронь у Timeline та готує стіл.
5.  **Візит:** Гість отримує нагадування, приходить у заклад. Статус броні змінюється на «Прийшов».
6.  **Навчання:** Система фіксує успішне бронювання та використовує ці дані для уточнення майбутніх прогнозів AI.
